# 0001: The docs site is cut from v0.1

**Date:** 2026-10-24 · **Decided by:** the owner · **Status:** decided

The docs site is cut from v0.1 and moves to the v0.2 backlog, where `docs/v0.2-backlog.md`
already lists it (item 8: "README suffices for v0.1"). `DESIGN.md` section 11 had it both in
the M3 scope and as the first item to slip, which contradicted the backlog; this decision
removes it from both places in section 11 so the three documents agree. The README is the only
user documentation in v0.1, which leaves M3 time for the release pipeline, the five rules and
the `capture` command; revisit if v0.1 users report that the README is not enough to install,
run and read a report.
